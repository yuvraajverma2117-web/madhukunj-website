# Asset provenance

## Supplied files

- `assets/menu-1.jpeg`, `assets/menu-2.jpeg`, `assets/cakes-menu.jpeg`, `assets/logo.jpeg`: retained unchanged from the original GitHub repository.
- `assets/brand-logo.png`: logo image extracted without visual alteration from page 3 of the user-supplied **MADHUKUNJ Brandbook by Pomelli.pdf**.
- `assets/pav-bhaji.png`: portrait food image extracted from page 6 of that brand book.
- `assets/kitchen-table.png`: landscape food image extracted from page 6 of that brand book.
- Original PDF extraction was lossless; no generative changes were made to the supplied imagery.

The hero and featured thali are displayed using a CSS crop of the thali pictured in `menu-2.jpeg`. The page labels the menu image as illustrative rather than guaranteeing an exact serving. Pav bhaji is the supplied brand-book imagery, not a new stock download.

## Original code-native assets

- Favicon: simple M monogram in scarlet and peach.
- Gulab jamun: original inline SVG illustration, labelled “Illustration”.
- Cake studio: procedural WebGL geometry authored in `src/cake3d.js`, not a photograph or a claim about a deliverable cake design.
- Leaves, spice accents, ornaments and scene fallback are CSS/SVG geometry.

## Typography

The brand book names Alfarn 2, but no licensed webfont file was supplied. The site uses a local Georgia-led display serif and system sans-serif stack instead of claiming to bundle that font. Replace the font variables with a licensed webfont if one is later provided.

## Content decisions

All priced dishes and the two-hours cake guidance come from the supplied menus. Some descriptions are original, non-specific promotional copy, not ingredient lists.

Removed unsupported claims about the exact address, opening days/hours, “first in town”, ratings, ingredient sourcing, number of flavours and baking history. No fictional testimonials or founding timeline were added. The story expresses the brand-book values without manufacturing historical facts.

The supplied photos and logo should remain authorised for the business's website use. No third-party stock-photo dependency remains.
