# Madhukunj Kitchen — Website

Landing page for **Madhukunj Kitchen** (मधुकुंज) — *Delight in every bite*.

A single-file, self-contained site (`index.html`) with GSAP/ScrollTrigger/Lenis
scroll animations, a hero word-cycler, a full-menu modal (real scanned menus),
and click-to-call ordering.

## Run

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

## Contents

- `index.html` — the site
- `assets/logo.jpeg` — Madhukunj logo
- `assets/menu-1.jpeg`, `assets/menu-2.jpeg` — full menu (opened via "View full menu")
